# 生物制剂及小分子药物

&lt;aside&gt;
📌

为临床快速使用而整理：用药前筛查、治疗中监测、禁忌与慎用，所有要点均依据中国银屑病生物制剂及小分子药物治疗指南（2024 版）来源保留本地(https://doi.org/10.35541/cjd.20240294)

&lt;/aside&gt;

---

## 用药前通用筛查与随访频率

| 筛查项目                         | 适用药物/人群              | 启动前   | 治疗中复查                          | 异常处理要点                               |
| ---------------------------- | -------------------- | ----- | ------------------------------ | ------------------------------------ |
| 血常规、肝肾功能                     | 所有生物制剂与小分子           | 必做    | 第 4、12 周，其后每 3–6 个月            | 中重度异常暂停并评估原因，必要时会诊                   |
| HBV 三项 + HBV-DNA（必要时）、HCV 抗体 | 所有生物制剂与 JAK/TYK2 抑制剂 | 必做    | HBV-DNA 阳性 1–3 个月；阴性 3–6 个月    | HBV-DNA 阳性先抗病毒预防 1–2 周，治疗期持续 6–12 个月 |
| 结核 IGRA/PPD + 胸片/CT          | 所有生物制剂与 JAK/TYK2 抑制剂 | 必做    | 启用后第 3、6 个月；其后每 6 个月（TNF-α 更严） | 活动性结核禁用；潜伏/非活动性先完成 ≥4 周预防性治疗         |
| 心电图 ± 超声心动图                  | TNF-α 或心衰高危          | 建议    | 依症状或风险不定期                      | III–IV 级心衰禁用 TNF-α；EF &lt; 50% 避免使用     |
| 妊娠检测（尿妊娠）                    | 育龄女性                 | 视病史酌情 | 需要时                            | 妊娠/哺乳用药需个体化窗口管理                      |
| ANA、抗 dsDNA                  | 出现狼疮相关症状或体征          | —     | 出现症状时                          | 考虑药物诱导狼疮，暂停并转诊评估                     |
| 血脂                           | JAK/TYK2、小分子；代谢综合征   | 建议    | 第 12 周后每 3–6 个月                | 显著升高按指南处理或调整用药                       |

## 生物制剂

&lt;aside&gt;

### 禁忌与慎用（类别速查）

| 类别           | 绝对禁忌                                | 相对禁忌/慎用                     |
| ------------ | ----------------------------------- | --------------------------- |
| TNF-α 抑制剂    | 活动性结核或严重感染；III–IV 级心力衰竭；未控制的活动性 HBV | 既往恶性肿瘤、脱髓鞘病、I–II 级心衰、反复严重感染 |
| IL-12/23 抑制剂 | 活动性严重感染                             | LTBI 未规范预防；HBV 携带需监测与预防     |
| IL-17A 抑制剂   | 活动性严重感染                             | 炎症性肠病病史/家族史慎用；复发性念珠菌感染倾向    |
| IL-23 抑制剂    | 活动性严重感染                             | LTBI 未规范预防；HBV 携带需监测与预防     |
| IL-36 抑制剂    | 活动性严重感染；既往严重超敏反应                    | 输注反应与迟发过敏（含 DRESS）需严密监测     |

## 小分子药物

&lt;aside&gt;
💊

包含 JAK、TYK2 与 PDE-4 抑制剂的筛查与监测表、禁忌与慎用

&lt;/aside&gt;

### 筛查与随访监测表

| 筛查项目                    | 适用药物                        | 启动前   | 治疗中复查                       | 说明要点                               |
| ----------------------- | --------------------------- | ----- | --------------------------- | ---------------------------------- |
| 血常规（CBC）                | JAK（托法替布、乌帕替尼）、TYK2（氘可来昔替尼） | 必做    | 第 4、12 周；其后每 3–6 个月         | 关注中性粒细胞与淋巴细胞下降；中重度异常暂停并评估          |
| 肝功能（ALT/AST）            | 全部小分子；JAK/TYK2 更需重点         | 必做    | 第 4、12 周；其后每 3–6 个月         | 持续升高按肝损害流程处理，必要时调整或停药              |
| 肾功能（SCr/eGFR）           | 阿普米司特                       | 建议    | 按基线/共病按需                    | 重度肾功能不全：阿普米司特 30 mg 每日一次           |
| 血脂（TC/LDL/HDL/TG）       | JAK、TYK2                    | 建议    | 第 12 周后每 3–6 个月             | 明显升高按心代谢指南管理或考虑方案调整                |
| CK（肌酸激酶）                | 乌帕替尼、氘可来昔替尼                 | 建议    | 每 3–6 个月或肌痛时                | 明显升高伴肌痛警惕肌病/横纹肌溶解，必要时停药            |
| HBV 三项 + HBV-DNA、HCV 抗体 | 全部小分子，JAK/TYK2 尤其需要         | 必做    | HBV-DNA 阳性 1–3 个月；阴性 3–6 个月 | HBV-DNA 阳性先抗病毒预防 1–2 周，治疗期 6–12 个月 |
| 结核 IGRA/PPD + 胸片/CT     | 全部小分子，JAK/TYK2 尤其需要         | 必做    | 启用后第 3、6 个月；其后每 6 个月（高危从严）  | 活动性结核禁用；潜伏/非活动性先 ≥4 周预防            |
| 心血管风险评估/心电图             | JAK（托法替布、乌帕替尼）              | 建议    | 按风险与症状                      | VTE/MACE 高风险慎用；必要时与心内科协作           |
| 妊娠检测（尿妊娠）               | 育龄女性（所有小分子）                 | 视病史酌情 | 需要时                         | 小分子妊娠/哺乳禁用，需个体化生育计划与替代方案           |
|                         |                             |       |                             |                                    |

### 禁忌症与慎用（药物速查）

| 药物 | 分类 | 绝对禁忌 | 慎用/高风险人群 | 观测重点 |
| --- | --- | --- | --- | --- |
| 阿普米司特 | PDE-4 | 妊娠/哺乳禁用 | 重度胃肠不耐受、抑郁高风险 | 起始 GI 反应、体重、（必要时）情绪；可监测血脂 |
| 托法替布 | JAK | 活动性感染（含结核）、妊娠/哺乳禁用 | VTE/MACE/恶性肿瘤高风险 | 按期 CBC、肝酶、血脂；带状疱疹与重感染预警 |
| 乌帕替尼 | JAK1 | 活动性感染、重度肝损伤、妊娠/哺乳禁用 | VTE/MACE/恶性肿瘤高风险 | CBC、肝酶、血脂、CK；重感染/带疱/血栓预警 |
| 氘可来昔替尼 | TYK2 | 活动性严重感染、妊娠/哺乳禁用 | 恶性肿瘤或肌病高风险 | CK、肝酶、甘油三酯；上呼吸道/疱疹；罕见横纹肌溶解 |
