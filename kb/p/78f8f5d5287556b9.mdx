# 文件归属决策树｜经营院长、部门与病种专业知识

> **important** 唯一执行口径
> 本页是 来源保留本地 的组织归属子树。出现冲突时，以《文件归属指引》及保密规则为准；Agent 每次分类前读取本页，不保留另一套独立分类规则。

## 核心分层

| 层 | 作用 | 是否存放原始附件 |
| --- | --- | --- |
| PARA 物理归属 | 决定文件唯一存放位置 | 是；原始附件存放在 8-素材库 |
| 部门职责 | 决定哪一部门负责维护、执行或复核 | 否；通过元数据、部门工作页和链接表达 |
| 病种专业知识 | 为医生、护理、病人关系等共同使用的银屑病知识入口 | 否；导航至资源库和原始来源 |

规则：一个文件只有一个物理主归属；跨部门、跨专业关系只建立链接，不复制正文或附件。

## 归属判断顺序

1. 新资料先进入 0-收件箱。
2. 含患者身份、病例细节或受限信息：原件进入 8-素材库的受限资料路径；只建立必要的授权导航。
3. 原始附件、外部文件或不可编辑来源：原件进入 8-素材库；不改写、不复制。
4. 已加工的银屑病疾病、诊疗、药物或循证知识：正式知识页进入 3-资源库的医学知识；导航至 [银屑病病种专业知识](/kb/p/bf2dbfb3b9c81885)。
5. 某一部门长期要执行、维护或培训的工作资料：正式工作页进入 2-领域下的责任部门目录。
6. 有交付物、负责人、结束条件的事项：进入 1-项目下的项目目录。
7. 已结束或失效但仍有保留价值的资料：进入 4-存档。
8. 信息不足或同时符合多个归属：留在 0-收件箱，提出分类建议，等待确认。

## Agent 执行方式

1. 读取原文、来源、现有路径、保密级别和上下文，而非仅按标题分类。
2. 生成分类台账：物理建议路径、责任部门、病种/业务入口、资料角色、置信度与待复核事项。
3. 先提交建议；未经确认不移动、不重命名、不建立批量正式关联。
4. 确认后：原始附件保留在素材库；正式工作页进入对应 PARA 板块；更新标签卡、MOC 与 来源保留本地。
